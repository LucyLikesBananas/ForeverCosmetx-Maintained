# ForeverCosmetx-Maintained

ForeverCosmetx was abandoned after its original creator left Gorilla Tag modding.
I've brought it back with major improvements while keeping its original goal, to never breaking, even when Gorilla Tags CosmeticController changes. 

Since theres no official to the old ForeverCosmetx, you can now get it here :white_heart:

Controls:
X - Open the PC GUI to Hide your CosmetX from Mod Checkers (Keyboard X)
